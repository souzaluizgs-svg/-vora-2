# Bancada K1·K2 — 4 lâmpadas com intertravamento

Simulador estilo CAD da montagem de comando com 2 contatores (220 V~), 4 lâmpadas, botoeiras NA/NF, DG trifásico e D1/D2 bifásicos.

- `index.html` — abra no navegador (arquivo único, sem instalação).
- `bancada-k1-k2.html` — mesmo conteúdo, sem o cabeçalho HTML (fonte do artifact).

Recursos: desenho de montagem ponto a ponto com 33 fios numerados, diagrama funcional, disjuntores e botões clicáveis, fluxo de corrente animado, multímetro, lista de fiação com checklist, ensaio automático e modo "Texto original" que reproduz os erros da descrição.
