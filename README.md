# Bancada K1·K2 — 4 lâmpadas com intertravamento

Diagrama de comando no estilo CADe_SIMU (mesma simbologia e numeração de bornes), simulável no navegador.

- `index.html` — abra no navegador (arquivo único, sem instalação).
- `bancada-k1-k2.html` — mesmo conteúdo, sem o cabeçalho HTML (fonte do artifact).

Recursos: disjuntores e botões clicáveis no desenho, contatos e bobinas ficam vermelhos quando energizados, modo "Texto original" que reproduz os erros da descrição e ensaio automático.
